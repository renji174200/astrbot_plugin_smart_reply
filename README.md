# 智能接话（astrbot_plugin_smart_reply）

让机器人自己决定什么时候开口，而不是「全回」或「按概率回」。

## 优势

- **打分制**：模型给 0~100 分，≥ 阈值才回复，阈值可调
- **不刷屏**：刚说过话的一段时间内自动提高门槛
- **硬规则兜底**：叫名字、引用它、催促词直接回，不依赖模型
- **失败可降级**：限流重试 3 次 → 备用模型 → 判不回
- **可观测**：每次判断写入 JSONL，能按分数分布调阈值
- **配置友好**：模型用下拉框选，数值带滑块

## 安装

1. 在 AstrBot 插件页安装本插件，或把目录放进 `data/plugins/`
2. 重启 AstrBot
3. 面板 →「插件」→ 智能接话 → 配置

## 必改配置

| 配置 | 说明 |
|---|---|
| `name_keywords` | 填你的机器人名字 / 群名片（必填） |
| `judge_provider_id` | 下拉选择判断模型，留空用当前对话模型 |

## 主要配置

| 配置 | 默认 | 说明 |
|---|---|---|
| `judge_threshold` | 60 | 分数线，越高越安静 |
| `recent_reply_bonus` | 15 | 刚回复后临时提高的门槛 |
| `context_size` | 30 | 判断时参考的历史条数 |
| `cooldown_sec` | 0 | 接话冷却 |
| `quiet_hours` | 空 | 免打扰时段，如 `1-8` |
| `decision_log` | true | 写判断日志 |

完整配置项见插件配置页。

## 判断日志

```
data/plugin_data/<插件目录名>/decisions.jsonl
```

每行包含 `score`、`text`、`sender`，可以统计分数分布来判断阈值是否合适。

## 判断回放面板

插件详情页打开「判断回放」：

- 最近 300 条判断记录 + 分数分布
- 逐条标注 `对` / `该回没回` / `不该回回了`
- 一键导出 few-shot 样例，贴回判断提示词

## 分群配置

`group_overrides` 可按群覆盖阈值等参数，例如：

```json
{"751997685": {"judge_threshold": 70}, "722324569": {"enable": false}}
```
